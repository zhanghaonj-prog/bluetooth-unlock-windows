# 开源发布准入清单

任何一项标记为“阻断”的条件未满足时，不得将仓库设为 Public 或发布自动解锁安装包。

## A. 权利与治理

- [ ] 阻断：确认代码、设计、名称和图标拥有公开发布权。
- [ ] 阻断：批准项目许可证。
- [ ] 阻断：完成 Credential Provider 来源对照和第三方归属。
- [ ] 添加 LICENSE、THIRD_PARTY_NOTICES、SECURITY、CONTRIBUTING。
- [ ] 配置行为准则、Issue/PR 模板和维护人。
- [ ] 明确漏洞私密接收渠道和响应时限。

## B. 数据脱敏

- [ ] 阻断：公开仓库从无私有历史的脱敏快照建立。
- [ ] 阻断：不跟踪真实 `config.json`、日志、诊断、校准和凭据。
- [ ] 阻断：删除真实 BLE 地址、SSID/Profile、用户名、SID、主机名和内部域名。
- [ ] 配置样例中的系统动作和自动解锁全部关闭。
- [ ] 运行 gitleaks、GitHub secret scanning 和自定义标识正则。
- [ ] 人工检查文档、测试夹具、截图和 Release 资产。

## C. 安全加固

- [ ] 阻断：Provider 验证 Broker 服务端身份并防止管道抢占。
- [ ] 阻断：Provider 管道读写和线程退出有整体截止时间。
- [ ] 阻断：错误密码不会在同一账户上持续自动重试。
- [ ] Broker 授权使用单调时钟并保持会话/锁屏周期绑定。
- [ ] 日志具备 ACL、轮转和诊断脱敏。
- [ ] 自动解锁默认不安装或禁用，并展示可逆密码风险。
- [ ] 一键禁用、卸载和离线恢复通过测试。

## D. 构建与供应链

- [ ] 阻断：CI 可从干净 Windows runner 构建所有组件。
- [ ] 阻断：Agent、Broker、Provider 和安装器完成 Authenticode 签名。
- [ ] 固定构建工具版本，记录 Visual Studio、SDK 和 Inno Setup 版本。
- [ ] 运行单元、协议、COM、PE、安装器和敏感信息测试。
- [ ] 生成 SBOM、逐文件清单和安装包 SHA-256。
- [ ] 启用 CodeQL 或同等级 C#/C++ 静态分析。
- [ ] Release 只能由受保护标签和审批后的 CI 生成。

## E. Windows 验收

- [ ] 阻断：Windows 10 x64 安装、升级、卸载和原生登录回退通过。
- [ ] 阻断：Windows 11 x64 安装、升级、卸载和原生登录回退通过。
- [ ] Modern Standby 交互唤醒通过。
- [ ] S3 在支持设备上通过，或明确标记为未验证。
- [ ] 密码修改、错误密码、账户锁定策略和 Microsoft Account 通过。
- [ ] Broker 停止、Provider 故障、网络切换和快速用户切换通过。
- [ ] 连续 30 次自动解锁和 24 小时稳定运行通过。

## F. 用户体验与文档

- [ ] README 准确说明功能、风险、支持版本和非目标。
- [ ] 首次配置可以选择“手表加手机”或“仅手机”。
- [ ] 安装后引导先验证手工登录，再启用自动解锁。
- [ ] 故障排查不要求用户公开提交密码、SID 或完整日志。
- [ ] 发布已知限制、隐私说明、恢复步骤和变更日志。

## G. 发布后

- [ ] 启用默认分支保护、必需检查和禁止强推。
- [ ] 开启 Dependabot、secret scanning 和安全公告。
- [ ] 监控安装/卸载与无法登录类高危问题。
- [ ] 为每个受支持版本定义安全修复期限。
- [ ] 高危漏洞具备撤回 Release 和发布紧急禁用说明的流程。
