# Code of Conduct

Project participants must communicate respectfully, focus criticism on technical work, and avoid
harassment, discrimination, threats, doxxing, or publication of another person's credentials, device
identifiers, network names, logs, or private environment details.

Maintainers may edit or remove content, reject contributions, or restrict participation when behavior
creates safety, privacy, or collaboration problems. Security reports must follow `SECURITY.md` and must
not be used to expose sensitive details in public Issues.

Report conduct concerns through the maintainer's private GitHub contact channel. Enforcement decisions
should be documented privately and applied consistently.
